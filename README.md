# Week 6 - Interactive Sales Dashboard

## Project Overview
This project creates an interactive sales dashboard using Python, Pandas, Matplotlib, and Seaborn. It analyzes sales data and generates multiple visual charts for better business insights.

## Features
- Product sales bar chart
- Region sales pie chart
- Correlation heatmap
- Price distribution boxplot
- Total revenue calculation
